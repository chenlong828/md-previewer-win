# REQ-0009：查看代码文件（只读高亮源码）

**类型**：feature

## 1. 场景叙述

当用户打开一个常见代码文件（`.swift` / `.py` / `.js` / `.ts` / `.go` / `.rs` / `.xml` / `.json` / `.yaml` 等）时，应用在同一个窗口模型里显示**只读的源码视图**：语言默认由扩展名推断并高亮，可从「视图 → 高亮语言」切换语言或关成纯文本，可滚动阅读、用 Ctrl+F 查找、用 Ctrl+E 导出 PDF / Ctrl+P 打印。

结果是：看一段源码不需要切到另一个编辑器；Markdown 与代码文件共用同一套打开、窗口、主题、缩放与查找习惯。

## 2. 价值

不做的后果：代码文件只能用外部编辑器打开；同一份仓库里 md 与代码要来回换应用，预览器只能预览 Markdown。

## 3. 非目标

- 不做编辑、保存、撤销、脏标记（代码文档恒只读）。
- 不做 WYSIWYG ⇄ 源码切换（代码文档只有源码视图）。
- 不做行号、折叠、minimap、语法语义（跳转/补全/LSP）。
- 不做 资源管理器「打开方式」关联（不注册 `Info.plist` 文档类型）。
- 不做代码文档的独立 HTML 导出（PDF / 打印保留）。
- 不保证超大文件高亮（超过阈值降级纯文本并提示）。

## 4. 约束

- 打开入口沿用现有模型：Ctrl+O、抽屉双击、拖放、命令行、最近文件、文档内链接；外部打开新窗口、当前窗口覆盖语义不变。
- 支持范围以 `FileSupport` 的语言表为唯一来源；web 语法表必须覆盖全部语言 id（selftest 双端一致断言）。
- 不新增依赖；高亮复用 refractor 与 `typora.css` 的 token 调色板，浅/深色随主题。
- 代码文档下：格式命令、源码模式、插入图片、保存/另存为、HTML 导出全部不可用；关闭不弹保存确认、不触发图片资源清理。
- 外部变更：干净文档自动重载，重载保留当前高亮语言选择。
- 单文件高亮上限 512 KB（UTF-8 字节）；超过则纯文本渲染并在状态栏标注。
