# REQ-0012：文档右键复制文件路径

**类型**：feature

## 1. 场景叙述

用户打开一个已保存的 Markdown 或代码文件，在正文上右键，选择「复制文件路径」，当前文件的
绝对路径写入系统剪贴板，可直接粘贴到终端、资源管理器、聊天窗口或脚本里。

未保存的新文档和目录模式没有文件路径，菜单里不出现该项。

## 2. 价值

不做的后果：只能从标题栏、资源管理器或打开面板间接获取路径，或按目录手动拼接；频繁引用
同一文件路径时操作链路过长且易错。

## 3. 非目标

- 不做「点击标题栏文件名复制路径」。
- 不做相对路径、`file://` URL、文件名、shell 转义等格式选择。
- 不把命令加进菜单栏；只进文档右键菜单。
- 不为未保存文档或目录模式伪造路径。
- 不写文件、不产生脏标记、不改文档内容。
- 不做复制成功的 toast/弹窗。

## 4. 行为约定

- 菜单项固定为「复制文件路径」，位于右键菜单文件组；Markdown 与代码文档都出现。
- 仅当窗口对应一个已保存文件时出现；未保存/目录模式不出现。
- 写入当前文件的绝对 Windows 路径（`Path.GetFullPath`），无 `file://` 前缀。
- 只写系统剪贴板；不写文件、不产生脏标记、不影响撤销栈。

## 5. 影响场景

| 场景 | 状态 | 本次新增/修改的断言 |

| [SCN-0018 文档右键复制文件路径](../../../md-previewer/doc/design/scenarios/editing/document-lifecycle/copy-file-path/scenario.md) | verified（上游） | 菜单项出现、路径精确、代码文档可用、未保存反例 |

受影响行为：文档右键菜单、剪贴板。不影响文件 IO、编辑、保存、导出、缩略图、抽屉、标题栏。

## 6. 验收

验收 = Windows 侧场景 `verified` + §4 约束未被违反。

自动化：`ContextMenuPlanTests` 覆盖已保存/未保存/代码文档；实机点验复制后粘贴得到 `C:\…`。
