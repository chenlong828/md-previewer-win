# REQ-0006：多窗口与外部打开

**类型**：feature

## 1. 场景叙述

用户用 Ctrl+N、拖放、资源管理器、命令行或目录模式打开多个文档时，每个文档得到独立窗口，应用保持单进程单任务栏图标；Ctrl+O 与「打开最近使用」在当前窗口替换打开，不额外开窗。

结果是：可以并排对照多个文档，又不会出现多个 任务栏 图标或重复窗口。

## 2. 价值

不做的后果：单窗口模型退化为“一次只能看一个文件”；外部打开一律新窗口会留下重复窗口；多 任务栏 图标违反 Windows 单实例应用模型。

## 3. 非目标

- 不做标签页、分屏、窗口组、会话恢复。
- 不做每窗口独立主题/缩放（应用级设置）。
- 不做同一文档多窗口同步编辑。

## 4. 行为约定

- 单进程、单任务栏；每个文档一个窗口。
- 外部打开（CLI/拖放/资源管理器/目录参数）默认新窗口；Ctrl+O/最近文件在当前窗口替换。
- 同一文档不在两个窗口同时打开。
- 目录模式只占一个窗口；双击文件退出目录模式并覆盖当前窗口。
- 退出应用时所有脏窗口先确认；取消则不退出。
