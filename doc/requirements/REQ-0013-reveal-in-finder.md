# REQ-0013：文档右键在资源管理器中定位文件

**类型**：feature

## 1. 场景叙述

用户打开一个已保存的 Markdown 或代码文件，在正文上右键，选择「在资源管理器中显示」，
资源管理器打开并选中当前文件；用户可直接重命名、移动、查看同级文件或拖拽。

未保存的新文档和目录模式没有文件路径，右键菜单里不出现该项。

## 2. 价值

不做的后果：想从当前文档跳到文件所在位置，必须切到资源管理器再按目录逐层找；文件层级
较深时路径成本很高。

## 3. 非目标

- 不新增第二套定位实现：文件菜单与右键共用同一执行体。
- 不改变文件菜单「在资源管理器中显示」在目录模式下定位抽屉根目录的行为。
- 不为未保存文档 / 目录模式在右键菜单里伪造目标。
- 不打开新的资源管理器窗口浏览整个目录；只选中当前文件。
- 不写文件、不产生脏标记、不影响撤销栈。

## 4. 行为约定

- 菜单项固定为「在资源管理器中显示」，紧跟「复制文件路径」下方。
- 仅当窗口对应一个已保存文件时出现；Markdown 与代码文档都出现。
- 点击后调用 `explorer.exe /select,"<绝对路径>"`，在资源管理器中选中当前文件。
- 未保存文档：右键菜单项不出现；直接调用定位入口返回 false，且不拉起资源管理器。
- 目录模式：右键菜单项不出现；文件菜单的既有入口定位抽屉根目录。
