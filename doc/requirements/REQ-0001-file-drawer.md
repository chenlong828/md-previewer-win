# REQ-0001：文件抽屉与目录模式

**类型**：feature

## 1. 场景叙述

当用户打开一个 Markdown 文件或一个目录时，左侧抽屉按当前文档所在文件夹展示可打开的 Markdown 文件树；用户可以展开/收起目录、通过顶部锚点切换到任意父级、拖拽抽屉与正文的边界调整宽度，双击文件在当前窗口打开。

结果是：跨文件浏览与目录导航不离开当前窗口，Typora 式单窗口工作流成立。

## 2. 价值

不做的后果：跨文件浏览只能反复 Ctrl+O 或最近文件；目录模式下无法发现同目录文档；单窗口模型退化为「一次只能看一个文件」。

## 3. 非目标

- 不做文件系统监听（目录变化需手动刷新）。
- 不做树内新建/删除/重命名。
- 不做多标签；双击仍在当前窗口覆盖打开。
- 不做双击分界线复位默认宽度。

## 4. 约束

- 单窗口单文档；宽度 160–480pt，且正文不窄于 320pt。
- 按层懒加载，展开目录时才读取下一层；目录树不一次性递归。
- 跳过隐藏条目、符号链接、`node_modules` 与包目录。
- 不改桥协议；抽屉状态跨窗口记忆。

## 5. 影响场景

| 场景 | 状态 | 本次新增/修改的断言 |
|---|---|---|
| [SCN-0001 浏览文件抽屉并打开文档](../../../md-previewer/doc/design/scenarios/navigation/file-drawer/browse-and-open/scenario.md) | designed | 目录模式空白编辑器；lazy 扫描；锚点父级链；双击同窗；宽度 160–480 / 正文 ≥320；根不可读抛错（反例） |

受影响行为：目录模式打开空白编辑器；外部打开文件时锚点默认文件所在目录；抽屉双击保持锚点。
