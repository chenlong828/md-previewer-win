# REQ-0008：显示偏好与自适应宽度

**类型**：quality

## 1. 场景叙述

用户可以在跟随系统与锁定浅/深色之间切换，用 Ctrl++ / Ctrl+− / Ctrl+0 调整缩放，正文宽度随窗口自适应（下限 860px，窄于下限出现横向滚动）；缩放与外观设置在重启后保留。

结果是：在不同屏幕、不同环境光下都能读得清，窄窗口也不会把表格/代码挤爆。

## 2. 价值

不做的后果：系统切换深色时编辑器刺眼或不可读；高分屏文字过小；窄窗口正文被压成一条线，表格/代码横向爆炸。

## 3. 非目标

- 不做自定义主题、字体、行高、配色编辑器。
- 不做每文档独立缩放/主题。
- 不做移动端/响应式断点布局。

## 4. 行为约定

- 外观：默认跟随系统；可在「视图 → 外观」锁定浅/深；切换实时生效。
- 缩放：Ctrl++ / Ctrl+− 步进，Ctrl+0 复位；比例持久化。
- 宽度：正文 100% 跟随窗体；收缩下限 860px；缩放下视觉下限恒定。
- 代码高亮 token 调色板浅/深双值，由单一规则生成。
