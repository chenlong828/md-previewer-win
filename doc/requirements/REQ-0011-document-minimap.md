# REQ-0011：右侧文档缩略图与定位

**类型**：feature

## 1. 场景叙述

当用户阅读一篇超过一屏的 Markdown 文档，或一个只读代码文件时，窗口右侧显示整页内容的缩略图（长文按固定宽度裁切并随滚动平移），并用一个视口框标出当前看到的位置；滚动文档时视口框同步移动，点击缩略图的页面内容区或拖动视口框即可跳转、连续定位。缩略图默认显示，可从「视图 → 显示文档缩略图」关闭，偏好跨窗口记忆；Markdown 源码模式不显示，内容短到无需滚动时自动不显示。

结果是：长文档不必靠拖动系统滚动条盲找位置，用户可以先看内容分布，再直接落到目标位置；缩略图只是阅读辅助，不改变正文、复制、查找、导出、文件内容或脏标记。

## 2. 价值

不做的后果：Markdown 与代码阅读面都只有系统滚动条，长文档无法一眼判断“后面还有多少、目标在哪”；代码视图尤其缺少 Sublime 使用习惯中的右侧缩略定位，读长文件要反复滚动试探。

## 3. 非目标

- 不做 Markdown 源码模式的缩略图；源码模式（`#source-editor`）不显示、菜单不可用。
- 不做目录/大纲/TOC、标题列表、章节折叠；缩略图只回答“全文长什么样、当前位置在哪”。
- 不在缩略图中标记查找命中、当前编辑光标、批注或 diff；不提供 hover 预览。
- 不允许在缩略图中编辑、选择文本、拖动内容、调整文档结构。
- 不做缩略图宽度拖拽、逐文档宽度、停靠/独立窗口；v1 固定宽度（120px 视觉宽）。
- 不把缩略图放进 PDF/打印/独立 HTML 导出；缩略图不是文档内容。
- 不承诺缩略图里的字逐字可读；像素级还原不是验收标准（见 §4 的“真缩略图”口径）。
- 不新增依赖，不引入 LSP、折叠、代码编辑、多标签等既有非目标。

## 4. 约束

- **覆盖内容面**：Markdown 渲染面（`#app`）与代码只读面（`#code-view`）；两者共用同一个缩略图组件与交互，但各自提供内容投影。
- **真缩略图口径**：Markdown/代码组件提供真实渲染 DOM 的只读快照，缩略图等比缩放后挂载；保留文字、表格、KaTeX、Mermaid、图片与代码 token 的真实视觉，不再用 Canvas 块示意。**页面始终顶左对齐，不横向居中**。
  - **短文档（fit）**：`scale = min(轨道宽/页面宽, 轨道高/页面高)`，整页可见；页面较窄/较短时右侧或下方留空。
  - **长文（crop）**：fit 后页面宽度低于 120px 时，改为 `scale = 轨道宽/页面宽`，页面宽固定 120px、高度可超过轨道；轨道纵向裁切，页面与视口框都按整篇滚动进度线性平移，视口框在轨道里的位置与滚动条进度同步，顶部/底部对齐文档开头/结尾。
  - 不承诺缩略图里的字逐字可读。视觉目标见归档工序 [compare.png](../../../md-previewer/doc/history/works/2026-11-04-document-minimap/compare.png)。
- **显示与开关**：默认显示；视图菜单「显示文档缩略图」可关，勾选状态反映偏好；偏好存 `UserDefaults["minimapVisible"]`，跨窗口共享、新窗口继承。偏好为“开”但内容不足一屏、处于源码模式或不可绘制时，实际不显示，菜单勾选仍保留偏好。
- **布局**：缩略图为 WebView 内右侧固定栏，v1 视觉宽 120px；正文为它预留空间，不覆盖正文，也不遮住系统滚动条；Ctrl+F 查找栏在缩略图显示时左移避让。窗口变窄时不做自动隐藏（正文已有 860px 横向下限），缩略图宽度保持固定。正文 860px 下限不变，因此窗口可视宽小于约 1006px 时会出现横向滚动；v1 接受这个代价，不用压缩正文/自动隐藏来回避。
- **滚动同步**：文档滚动只更新视口框，不重建快照；快照只在文档/主题/缩放/尺寸变化后按 250ms 防抖重建。滚动同步必须走 `requestAnimationFrame`，不得在滚动事件里同步测量整篇 DOM，也不得每帧重建快照。
- **交互**：点击/拖动坐标必须以**页面实际缩略矩形**为基准，不得按整条轨道 100% 折算；轨道空白区不响应定位。点击内容把目标位置居中到视口；在视口框上按下拖动连续滚动：fit 按 `contentHeight / docHeight` 换算，crop 把视口框当作整篇滚动条滑块、按 `railHeight - boxHeight` 1:1 跟手；结果夹取到 `[0, docHeight - viewportHeight]`。不抢编辑器焦点，不产生文本选区，不触发右键菜单。
- **不改变内容语义**：缩略图只读投影，不写 `state.lastMarkdown`/`state.codeText`，不发 `changed`，不进脏基线；复制、Ctrl+F、PDF/打印、HTML 导出结果不变。
- **快照预算**：只在缩略图有效显示时克隆；内容/主题/缩放/窗口尺寸变化才重建，滚动只更新视口框与裁切平移。典型长文快照目标 ≤50ms、滚动视口更新 ≤1ms；超预算先排查克隆与脱敏，不以回到 Canvas 掩盖。
- **失败退化**：快照创建/测量异常时隐藏缩略图并记录一次警告，不影响正文；图片/图表加载失败保留原占位或空框，不阻断其他内容；空文档、无溢出、源码模式、目录模式空文档都不显示。
- **无新增桥语义破坏**：Swift→JS 只新增向后兼容的可见性入口；既有 `init`/`setMarkdown`/`setCode`/`setTheme`/`setZoom` 语义不变。
- **导出隔离**：`@media print` 隐藏缩略图并取消正文预留；HTML 导出仍只取编辑器内容，不包含缩略图 DOM。
