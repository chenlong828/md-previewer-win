# REQ-0010：代码视图行号与按行阅读

**类型**：feature

## 1. 场景叙述

当用户在只读代码视图里阅读一个代码文件时，左侧按逻辑行显示行号；长行自动软换行，行号始终对齐该逻辑行的第一视觉行；点击某行或在 Ctrl+F 命中之间跳转时，高亮当前行；可从「视图 → 显示行号」开关行号，开关状态跨窗口记忆。

结果是：读长代码时能直接报出行号、按行定位，不需要另开编辑器数行；行号只是阅读面，不改变文件内容、复制文本、查找结果或导出语义。

## 2. 价值

不做的后果：代码视图只能整块阅读，长文件无法快速报行号/定位；软换行缺失时长行必须横向滚动，读代码时视线与行号脱节；行号常驻又无法关闭，对只需要看代码的用户是噪音。

## 3. 非目标

- 不做代码编辑、光标插入、选中行编辑、行号点击跳转到外部编辑器。
- 不做折叠、minimap、LSP、跳转/补全、行内 diff、git blame。
- 不给 Markdown 编辑器里的围栏代码块加行号；行号只属于 `#code-view` 代码阅读面。
- 不做按文件持久化的行号开关（开关是全局阅读偏好，不写入被打开的文件，不产生 `changed`）。
- 不做行号参与复制文本、Ctrl+F 查找文本、HTML 导出或代码内容哈希。
- 不改变代码文档「只读、无脏标记、无保存」的既有边界。

## 4. 约束

- 不新增依赖；软换行与行号用现有 DOM/CSS 实现，token 配色继续走 `typora.css` 唯一调色板。
- 行号是表现层：`state.codeText` 仍是唯一文本真源；代码字符、行数、复制结果、查找偏移与现有实现一致。
- 行号栏与文本分离：复制/选择不能带出行号数字；空行在复制时不能丢失。
- 软换行后，行号对齐逻辑行首，不按视觉折行重复编号；长 token 允许在任意位置断行，不产生横向代码滚动条。
- 行号开关为全局偏好（UserDefaults），默认开启；切换后所有已打开代码窗口即时生效，新窗口继承；Markdown 窗口不显示该菜单项为可用。
- 单文件高亮上限 512 KB 不变；超大文件仍走既有纯文本降级，行号行为不得让打开路径变慢或报错。
- PDF/打印沿用 `#code-view` 内容面；行号是否出现由当前开关决定，不另开导出设置。
- 不改变桥既有 op 语义；新增能力为向后兼容增量。

## 5. 影响场景

| 场景 | 状态 | 本次新增/修改的断言 |
|---|---|---|
| [SCN-0016 打开并查看代码文件](../../../md-previewer/doc/design/scenarios/editing/document-lifecycle/view-code-file/scenario.md) | verified | 逻辑行行号；软换行无横向溢出；空行复制保真；点击/Ctrl+F 当前行高亮；行号开关即时生效且不改变文本；空文件边界；PDF/打印包含行号（人工） |

受影响行为：代码视图渲染结构、Ctrl+F 命中后的当前行、复制全部代码、PDF/打印截图；不影响 Markdown 编辑、文件 IO、抽屉过滤。
